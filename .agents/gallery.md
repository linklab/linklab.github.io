# 홈페이지 갤러리

- 사진 갱신은 별도 저장소 `linklab/linklab-gallery`에서 관리한다.
- `index.html`은 `https://linklab.github.io/linklab-gallery/1.jpg`~`4.jpg`를 이미지와 원본 보기 링크로 사용한다.
- 홈페이지 저장소에 주기적으로 이미지를 커밋하거나 사진 다운로드 작업을 다시 추가하지 않는다.
- 갤러리 저장소는 매일 한국 시간 정오에 사진을 생성해 Pages에 직접 배포한다.
- 새 사진은 홈페이지 재배포 없이 반영되며 GitHub 예약 작업과 CDN 캐시 때문에 지연될 수 있다.
- 이미지 URL을 변경할 때 데스크톱·모바일 표시와 원본 보기 링크를 함께 확인한다.
